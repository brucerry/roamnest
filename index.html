    Saved on your device

    Trips and language are saved only in this browser. Exports contain your itinerary and any legacy records; keep them private.

    Keep a backup: browser storage can be cleared or unavailable.

    Location choices

    Opening Explore makes at most one GeoJS / Cloudflare IP lookup per page session. No GPS or trip data is sent; IP and location are not saved. VPNs may change the result.

    Privacy ↗

    Reset location requests device positioning only when clicked. If unavailable, it falls back to the optional IP lookup. Device coordinates stay in this page memory and are not saved or sent to providers.

    External directions

    Directions open Google Maps separately. This stop requests browser location, then optional IP if enabled; the selected origin is sent to Google Maps. Previous and Next start at this attraction. No precise location is saved.
